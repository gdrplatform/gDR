# gDR: Umbrella package for R packages in the gDR suite

Package is a part of the gDR suite. It reexports functions from other
packages in the gDR suite that contain critical processing functions and
utilities. The vignette walks through the full processing pipeline for
drug response analyses that the gDR suite offers.
